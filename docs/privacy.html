一亩三分地每日助手 · 隐私政策

最近更新：2026-09-09 · 本扩展是独立开发的非官方工具，与 1point3acres / 一亩三分地无关，未获官方授权。

收集什么

  • 你在每日答题页确认并保存的答案。
  • 当日签到 / 答题是否完成等进度。
  • 若你配置了本地调度，会保存计划时间。
  • 内容脚本会读取每日签到页、每日答题页上的题目、选项和页面状态，以便辅助操作。

不收集什么

不收集账号、密码、Cookie 或浏览历史；不接入分析、广告或远程服务器；不调用站点私有接口。

存在哪里、和谁共享

上述数据只写在本机 chrome.storage.local。不上传、不共享、不出售。内置题库随扩展安装在本地，仅用于本机匹配。

权限用途

  • storage：保存本机学习答案、当日进度，以及你已配置的本地调度状态。
  • notifications：签到成功或整次「一键签到 & 答题」完成后发送一条桌面通知。
  • alarms：在 service worker 被挂起后唤醒以收尾任务结果；仅当你已配置本地调度时用于定时，不会在未配置时自行创建任务。
  • https://1point3acres.com/* 与 https://www.1point3acres.com/*：打开、核验并在成功后关闭签到/答题任务标签页，并仅在 /next/daily-checkin 与 /next/daily-question 注入辅助界面。

卸载

从 Chrome 移除扩展后，上述本机数据会被浏览器删除。

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
